# Prepwise — requirements

Owner: SM · Status: agreed for v1 · Design: Figma `dN7B8ZKjYGrKkLAbqBfOfz`

## Who it's for

- **Students:** Year 4–7 children preparing for the 11+ (GL Assessment, CEM and independent/ISEB styles, mixed).
- **Parents:** set up children, approve weekly questions, track progress.
- **Groups:** invite-only. A parent creates a group and shares an invite code with other families.
  Rankings only ever compare children inside the same group.

## Functional requirements

| ID | Requirement | Priority |
|---|---|---|
| R1 | Separate sign-in for parents (email + password) and children (pick profile + 4-digit PIN on a device a parent has signed in on). | Must |
| R2 | A parent can add, edit and remove their children (nickname, year group 4–7, exam style mix, PIN). | Must |
| R3 | A parent can create a group, get an invite code, and invite other families. Codes can be resent by email. | Must |
| R4 | Each week, the system drafts a 30-question test per child: 15 Maths, 15 English, levelled to year group and weak topics. | Must |
| R5 | Drafts are generated by AI and must be **approved by a parent** before release. Parent can edit, swap, flag or regenerate any question. Flagged questions block release. | Must |
| R6 | Tests release Monday 07:00 (Europe/London) and are due Sunday 23:59. 25-minute timer. | Must |
| R7 | During a test a child can flag a question for later, use a rough-work scratchpad, skip, and go back. | Must |
| R8 | Tests are marked automatically on submit. Results show score, points, time, subject split and the mistakes to review. | Must |
| R9 | Points: 10 per correct answer, +3 for a "Challenging" question, +50 for completing on time, +20 for beating your previous best. | Should — tune later |
| R10 | Weekly ranking (resets Monday 00:00) and all-time ranking within the group. Only the top 3 are shown by rank; everyone else sees milestone tiers and their own position. | Must |
| R11 | Parent dashboard: score trend, subject split, topic mastery (≥80 strong, 60–79 watch, <60 focus), recent tests, "focus this week". | Must |
| R12 | Weak topics (<60%) automatically get extra, easier questions in the next week's draft. | Should |
| R13 | Step-by-step review of incorrect answers with hints, then the worked solution. | Should |
| R14 | Practice mode outside the weekly test, by topic, earning a small number of points. | Could |

## Non-functional requirements

| ID | Requirement |
|---|---|
| N1 | Mobile-first responsive UI (390px) with a desktop layout (1440px); installable as a PWA. |
| N2 | WCAG 2.2 AA: text contrast ≥ 4.5:1, touch targets ≥ 44px (answer tiles 64px). |
| N3 | Child data minimised: nickname, year group, PIN hash only. No child email, surname, photo or school. |
| N4 | Runs locally with `docker compose up` on SM's Mac; data in a Postgres volume; nightly `pg_dump` backup. |
| N5 | All data stored in PostgreSQL; schema managed by Flyway. |
| N6 | Every user-visible behaviour has a Gherkin scenario; every class has unit tests written first. |
| N7 | AI calls are made only by the backend, rate-limited, logged without personal data, and cost-capped per week. |

## Out of scope for v1

Payments, public sign-up, native app-store apps, teacher accounts, chat between users.

## Open questions

- Exact points formula (R9) — start with the above, revisit after 4 weeks of real use.
- Whether younger siblings (Year 4) should see the group ranking at all, or only their own progress.
